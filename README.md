# Downtime Reduction Analyzer

เว็บวิเคราะห์งานซ่อมเครื่องล้างรถ **QW & WAG** — ไฟล์เดียว ทำงานในเบราว์เซอร์ล้วน ๆ

**เปิดใช้งาน:** https://peatz1472.github.io/downtime-analyzer/

## 🔒 ต้องลงชื่อเข้าใช้

ข้อมูลงานซ่อมในหน้านี้ถูก **เข้ารหัส AES-256-GCM** ไว้ กุญแจถูกสร้างจากชื่อผู้ใช้และ
รหัสผ่านด้วย PBKDF2-SHA256 600,000 รอบ **ในเครื่องของผู้เข้าชมเอง**

- ไม่มีรหัสผ่านที่ถูกต้อง = เปิดอ่านข้อมูลไม่ได้จริง ๆ ไม่ใช่แค่ถูกซ่อนหน้าจอ
- รหัสผ่านไม่ได้ถูกเก็บไว้ในไฟล์ และไม่ถูกส่งออกไปที่ไหนทั้งสิ้น
- ปิดแท็บแล้วล็อกใหม่ทันที — ไม่มีการเขียนข้อมูลลงเครื่องผู้เข้าชม

ขอรหัสผ่านได้จากผู้ดูแลระบบ
